# 🎭 Face Detection System using OpenCV DNN

A simple, efficient face detection system using OpenCV's Deep Neural Networks module. Real-time webcam detection with a clean, easy-to-use interface.

## ✨ Features

- ✅ Real-time face detection from webcam
- ✅ Multiple face detection in single frame
- ✅ Adjustable confidence threshold
- ✅ Save snapshots during detection
- ✅ Performance statistics (FPS, face count)
- ✅ Simple command-line interface
- ✅ Test mode with synthetic images

## 📋 Requirements

- Python 3.7 or higher
- Webcam (built-in or external)
- 2GB RAM minimum
- 500MB disk space
